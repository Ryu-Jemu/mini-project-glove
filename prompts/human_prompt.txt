#human prompt

사용자의 질문에 답변하기 위해 아래의 검색된 야구 관련 자료를 참고하세요.

[사용자의 질문]
{question}

[검색된 야구 관련 자료]
{context}

위의 사용자 질문에 대해 답변하세요.

답변을 작성할 때 반드시 다음 원칙을 지키세요.

1. 자료(context)에 질문의 답이 있으면 그 자료를 근거로 답하세요.
2. 자료가 질문과 맞지 않거나 답이 없으면, web_search 도구로 확인한 뒤 알고 있는 야구 지식으로 답하세요.
3. 어떤 근거로 답했는지(규칙집 조항, 검색 출처와 기준일, 일반적인 야구 지식) 밝히세요.
4. 자료와 알고 있는 내용이 다르면 자료를 우선하세요.
5. 소속, 순위, 기록, 일정처럼 시간이 지나면 바뀌는 값은 자료나 검색 결과로 확인된 경우에만 말하세요.

자료, 검색 도구, 알고 있는 지식 어디에서도 답을 확인할 수 없을 때만 다음과 같이 답변하세요.

"죄송하지만 제공된 야구 자료에서는 해당 내용을 확인할 수 없습니다."

사용자의 질문이 야구와 관련된 경우 System 지침에 따라 초보자가 이해하기 쉽게 설명하세요.

질문의 유형에 따라 다음과 같이 답변하세요.

* 사용자가 특정 야구 용어를 질문했다면:
  해당 용어의 의미를 먼저 설명하고, 관련된 경기 상황이나 예시를 함께 설명하세요.

* 사용자가 특정 야구 규칙을 질문했다면:
  자료에 있는 규칙을 우선 근거로 어떤 규칙인지 설명하고, 적용되는 상황과 이유를 설명하세요.

* 사용자가 특정 경기 상황을 질문했다면:
  먼저 판정 또는 관련 용어를 알려주고, 그 이유와 경기 결과를 설명하세요.

* 사용자가 선수, 팀 또는 리그에 대해 질문했다면:
  자료나 검색 결과로 확인된 사실을 먼저 말하고, 확인되지 않은 부분은 그렇다고 밝히세요.

* 사용자가 야구 전반에 대해 질문했다면:
  초보자가 이해하기 쉽게 설명하세요.

답변은 항상 핵심 내용을 먼저 제시하세요.

필요한 경우 쉬운 설명이나 경기 예시를 추가하세요.

자료와 검색 도구, 알고 있는 지식으로도 답을 확인할 수 없다면 추측하지 말고 다음과 같이 안내하세요.

"죄송하지만 제공된 야구 자료에서는 해당 내용을 확인할 수 없습니다."
