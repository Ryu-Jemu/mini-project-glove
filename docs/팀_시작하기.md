# 팀원 시작 가이드

이 문서 하나로 저장소를 내려받아 **KBO 야구 규칙 도우미**를 로컬에서 띄울 수 있다.
막히면 맨 아래 "자주 나는 오류"를 먼저 본다.

## 0. 준비물

| 항목 | 최소 버전 | 확인 명령 | 없을 때 |
|---|---|---|---|
| Docker Desktop | 29 이상 (Compose v2) | `docker compose version` | docker.com 에서 설치 후 **실행해 둘 것** |
| uv | 0.12 이상 | `uv --version` | `curl -LsSf https://astral.sh/uv/install.sh \| sh` |
| Python | 3.12 | `uv python list` | uv 가 자동으로 3.12 를 받아온다 |
| OpenAI API 키 | — | — | platform.openai.com → API keys |

Python 은 직접 설치하지 않아도 된다. uv 가 `.python-version`(3.12)을 보고 알아서 맞춘다.

디스크는 약 1.5 GB 를 쓴다. 가상환경 603 MB, Docker 이미지 868 MB(pgvector 640 MB + MinIO 228 MB), 저장소 8 MB 다.

## 1. 내려받기

```bash
git clone <저장소 주소> mini-project-glove
cd mini-project-glove
```

이미 받아둔 사람은 최신으로 맞춘다.

```bash
git pull origin master
```

## 2. 환경 변수 만들기

`.env` 는 저장소에 올라가지 않는다. 각자 자기 것을 만든다.

```bash
cp .env.example .env
```

편집기로 `.env` 를 열고 **`OPENAI_API_KEY` 한 줄만** 채우면 일단 동작한다.
나머지는 기본값이 로컬 Docker 를 가리키므로 건드리지 않는다.

```
OPENAI_API_KEY=sk-...          # 필수
TAVILY_API_KEY=                # 선택. 없으면 웹 검색만 꺼진다
LANGCHAIN_API_KEY=             # 선택. 없으면 추적만 꺼진다
YOUTUBE_KBO_API_KEY=           # Phase 2 용. 지금은 비워도 된다
```

키 값은 절대 채팅·이슈·커밋에 붙여넣지 않는다. 키가 유출되면 결제가 그대로 청구된다.

## 3. 한 번만 실행하는 셋업

```bash
make setup
```

이 명령이 순서대로 다음을 한다.

1. `uv sync` 로 의존성 설치
2. `docker compose up -d` 로 Postgres(pgvector)·MinIO 기동
3. 두 컨테이너가 healthy 가 될 때까지 대기
4. DB 스키마 생성
5. 규칙 PDF 를 MinIO 에 업로드
6. PDF 를 파싱·분할·임베딩해 색인 (701 청크, OpenAI 임베딩 비용 약 **$0.016** 1회)
7. `doctor` 로 전체 점검

마지막에 `준비 완료` 가 보이면 성공이다. 5~10분 걸린다.

색인은 DB 에 남으므로 두 번째부터는 `make setup` 을 다시 돌려도 `skipped` 로 넘어가고 돈이 들지 않는다.

## 4. 실행

터미널 두 개가 필요하다.

```bash
# 터미널 1 — 백엔드
make api

# 터미널 2 — 화면
make ui
```

브라우저에서 http://127.0.0.1:8501 을 연다.
사이드바에 `● 준비됨` 과 청크 수가 보이면 정상이다.

끝낼 때는 각 터미널에서 Ctrl+C, 컨테이너는 `make down` 으로 내린다.
컨테이너를 내려도 색인 데이터는 Docker 볼륨에 남는다.

## 5. 잘 되는지 확인하기

예시 질문 세 개를 순서대로 눌러 본다.

| 질문 | 기대 결과 |
|---|---|
| 인필드 플라이가 뭐야? | 규칙 근거와 함께 설명, 하단에 `규칙집 근거 N건` 배지 |
| 오늘 서울 날씨 어때? | `죄송하지만 저는 야구와 관련된 질문에 대해서만 답변할 수 있습니다.` |
| 지금 KBO 순위 알려줘 | 웹 검색 결과 기반 답변 또는 자료 없음 안내 |

명령줄로도 확인할 수 있다.

```bash
make test        # 95개 단위·통합 테스트, API 키 불필요, 2초
make doctor      # 키·DB·MinIO·프롬프트 해시 점검
./bin/br python rag.py "보크가 뭐야?"
```

## 6. 코드를 고칠 때

- `make test` 가 통과해야 한다. 키 없이도 돌아가도록 되어 있다.
- `prompts/system_prompt.txt` 와 `prompts/human_prompt.txt` 는 **바이트 단위로 고정**이다.
  sha256 이 코드에 박혀 있어 한 글자만 바뀌어도 앱이 뜨지 않는다. 수정하지 않는다.
- 색인 로직(`chunker.py`, `pdf_parser.py`)을 바꿨다면 재색인이 필요하다.
  ```bash
  ./bin/br python -m baseball.ingest --force
  ```
- PDF 를 바꾸지 않았는데 색인만 다시 하고 싶으면 위 명령이면 충분하다. DB 를 지울 필요는 없다.

## 7. 자주 나는 오류

**`ModuleNotFoundError: No module named 'baseball'`**
macOS 가 가상환경의 `.pth` 파일에 숨김 속성을 붙여 파이썬이 무시하는 문제다.
`make` 명령은 `bin/br` 래퍼를 거치므로 자동으로 풀린다. 직접 `uv run` 을 쓰지 말고 `./bin/br` 를 쓴다.
수동으로 풀려면 `make fix-pth`.

**`포트가 이미 사용 중` / `address already in use`**
이전 프로세스가 남아 있다. 어떤 프로세스인지 먼저 확인하고 종료한다.
```bash
lsof -iTCP:8000 -sTCP:LISTEN
lsof -iTCP:8501 -sTCP:LISTEN
```

**`402` 또는 `OpenAI 사용 한도를 초과해 답변을 만들 수 없습니다`**
OpenAI 프로젝트의 지출 한도에 걸린 것이다. 코드 문제가 아니다.
platform.openai.com → 해당 프로젝트 → Limits 에서 한도를 올리거나 결제 수단을 확인한다.
한도에 걸리면 임베딩도 막히므로 검색 품질이 함께 떨어진다.

**사이드바가 `준비 안 됨`**
백엔드가 떠 있지 않다. `make api` 터미널을 확인한다.
`curl http://127.0.0.1:8000/readyz` 가 JSON 을 돌려주면 백엔드는 정상이다.

**`docker: Cannot connect to the Docker daemon`**
Docker Desktop 이 실행 중이 아니다.

**컨테이너가 healthy 로 안 바뀜**
```bash
docker compose logs --tail 50
```
포트 55432 나 59000 을 다른 프로그램이 쓰고 있을 수 있다.

## 8. 팀 규칙

- `.env` 는 절대 커밋하지 않는다. `.gitignore` 에 들어 있지만 `git add -f` 로 강제하지 않는다.
- OpenAI 키는 각자 발급해 각자 쓴다. 한 키를 공유하면 한 사람이 한도를 다 쓴다.
- 모든 포트는 `127.0.0.1` 에만 바인딩되어 있다. 외부에 열지 않는다.
- MinIO 는 로컬 전용이다. 미패치 취약점(CVE-2025-62506)이 있어 외부 노출 금지.
- 규칙 PDF(`data/2026_야구규칙.pdf`, 5.2 MB)는 저장소에 포함되어 있다. 따로 받을 필요 없다.

## 9. 명령 요약

| 명령 | 하는 일 |
|---|---|
| `make setup` | 최초 1회 전체 준비 |
| `make api` | 백엔드 실행 (8000) |
| `make ui` | 화면 실행 (8501) |
| `make test` | 테스트 95개 (키 불필요) |
| `make doctor` | 환경 점검 |
| `make up` / `make down` | 컨테이너 기동 / 정지 |
| `make ingest` | 재색인 |
| `make eval` | 골든셋 평가 (API 비용 발생) |
