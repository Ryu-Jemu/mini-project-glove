# 배포 가이드

**Streamlit Community Cloud 한 프로세스에 UI 와 RAG 서비스를 함께 올리고, 벡터 인덱스는 Neon 에 둔다.**
카드 등록 없이 전부 무료로 동작한다.

---

## 1. 왜 이 구조인가

백엔드는 상주 메모리가 약 600 MB 다. 형태소 분석기와 검색 색인을 메모리에 올리기 때문이다.
무료 컨테이너 호스트를 조사한 결과는 다음과 같다.

| 후보 | 무료 메모리 | 판정 |
|---|---|---|
| Streamlit Community Cloud | 690 MB ~ 2.7 GB | 충분하다 |
| Render 무료 웹 서비스 | 512 MB | 모자란다 |
| Koyeb 무료 인스턴스 | 512 MB | 모자란다 |
| Google Cloud Run | 지정 가능 | 카드가 필요하다 |
| Oracle Cloud Always Free | 12 GB | 카드가 필요하다 |

카드 없이 600 MB 를 감당하는 별도 호스트는 없었다.
반면 Community Cloud 자체가 그만큼을 주므로 **백엔드를 같은 앱 안에서 돌린다.**

데이터베이스만 외부에 둔다. Neon 무료 요금제는 카드가 필요 없고 영구적이며 pgvector 를 모든 요금제에서 제공한다.

---

## 2. 동작 방식

`ui/backend.py` 가 실행 환경을 보고 두 경로 중 하나를 고른다.

| 조건 | 모드 | 동작 |
|---|---|---|
| `API_BASE_URL` 있음 | `api` | FastAPI 백엔드를 SSE 로 호출한다. 로컬 개발이 여기 해당한다 |
| `API_BASE_URL` 없음 | `inprocess` | 같은 프로세스에서 RAG 서비스를 직접 호출한다. 배포본이 여기 해당한다 |

두 경로는 `(event, data)` 튜플이라는 같은 계약을 낸다. 그래서 `ui/app.py` 는 어느 쪽이든 바뀌지 않는다.
`APP_MODE` 환경변수로 강제할 수도 있다.

로컬은 `make ui` 가 `API_BASE_URL` 을 넣어 주므로 기존 방식 그대로 동작한다.

---

## 3. 의존성 해석

Community Cloud 는 엔트리포인트 디렉터리를 먼저 찾고 그다음 저장소 루트를 찾는다.
각 위치에서 `uv.lock`, `Pipfile`, `environment.yml`, `requirements.txt`, `pyproject.toml` 순으로 우선하며
찾은 첫 파일 하나만 쓴다.

```
ui/requirements.txt      ← 엔트리포인트 옆이므로 이것이 이긴다
uv.lock                  ← 루트. 무시된다
```

`ui/requirements.txt` 에는 답변 경로에 필요한 것만 담는다.
색인 전용 패키지와 FastAPI 는 제외한다. 파일 안에 제외 사유를 적어 두었다.

## 4. 메모리

| 구성 | 상주 |
|---|---|
| 화면만 | 52 MB |
| 올인원 | 617 MB |

최소 보장치 690 MB 대비 여유가 약 70 MB 다. 한도 초과가 나면 다음 순서로 줄인다.

1. 검색 색인 빌드 후 원본 토큰 목록을 버린다.
2. 기준 점수를 색인 시점에 미리 계산해 저장한다.
3. 형태소 분석기의 기본 사전을 끈다. 품질 영향을 평가로 확인한다.
4. 마지막 수단으로 어휘 검색을 끄고 벡터 검색만 쓴다. 한국어 용어 매칭 품질이 떨어진다.

형태소 분석기의 다어절 고유명사 사전은 이미 꺼 두었다.

## 5. 배포 절차

### 5.1 데이터베이스 준비

1. neon.com 에서 프로젝트를 만든다. 카드가 필요 없다.
2. 연결 문자열을 복사한다. 색인에는 풀러가 붙지 않은 직접 연결을 쓴다.
3. 로컬에서 원격 데이터베이스에 색인을 넣는다. 색인 명령만 MinIO 를 쓰므로 컨테이너를 켜 둔다.
   ```bash
   make up
   PG_DSN='<직접 연결 문자열>' ./bin/br python -m baseball.db ensure
   PG_DSN='<직접 연결 문자열>' ./bin/br python -m baseball.storage sync
   PG_DSN='<직접 연결 문자열>' ./bin/br python -m baseball.ingest
   ```
4. 결과를 확인한다.
   ```bash
   PG_DSN='<연결 문자열>' ./bin/br python -m baseball.retriever "인필드 플라이가 뭐야?"
   ```

연결 문자열은 `.env` 에 넣지 않는다. 넣으면 로컬 명령이 전부 원격을 가리키게 되고,
초기화 명령이 원격 데이터를 지울 수 있다. 명령마다 앞에 붙여 쓴다.

### 5.2 앱 배포

1. share.streamlit.io 에 GitHub 으로 로그인한다.
2. 좌측 상단에서 GitHub 저장소 접근 권한을 연결한다. 로그인과 별개의 단계다.
3. Create app 을 누르고 기존 앱이 있다고 선택한다.
4. 저장소, 브랜치, 파일 경로 `ui/app.py` 를 넣는다. 주소 칸에 원하는 이름을 넣는다.
5. Advanced settings 를 연다.
6. 파이썬 버전을 3.12 로 맞춘다. **배포 후에는 바꿀 수 없다.**
7. Secrets 에 다음을 붙여 넣는다. 모든 값을 따옴표로 감싼다.
   ```toml
   OPENAI_API_KEY = "sk-..."
   PG_DSN = "postgresql://...-pooler.../neondb?sslmode=require&channel_binding=require"
   OPENAI_CHAT_MODEL      = "gpt-4o-mini"
   OPENAI_EMBEDDING_MODEL = "text-embedding-3-large"
   EMBEDDING_DIMENSIONS   = "1024"
   ENABLE_WEB_SEARCH      = "auto"
   MAX_TOOL_ROUNDS        = "2"
   APP_ACCESS_PIN         = "<직접 정한 숫자 4자리>"
   TAVILY_API_KEY         = "tvly-..."
   ENABLE_SCHEDULE_TOOL   = "on"
   ENABLE_HIGHLIGHTS      = "on"
   YOUTUBE_KBO_API_KEY    = "AIza..."
   ENABLE_PLACES          = "on"
   ENABLE_PLACES_MAP      = "on"
   GOOGLE_MAPS_EMBED_API_KEY = "AIza..."
   RULEBOOK_PDF_URL = "https://github.com/Ryu-Jemu/mini-project-glove/blob/develop/data/2026_%EC%95%BC%EA%B5%AC%EA%B7%9C%EC%B9%99.pdf"
   ```
   **`PG_DSN` 에 `.env.example` 의 기본값을 넣으면 안 된다.** 그 값은 내 컴퓨터의 도커 주소라
   배포지에서는 자기 자신을 가리켜 연결에 실패한다. Neon 대시보드에서 복사한 주소를 넣는다.

   `RULEBOOK_PDF_URL` 은 사이드바의 "원문 PDF 열기" 주소다. 주소에 브랜치 이름이 들어가므로
   배포 브랜치를 바꾸면 이 값도 같이 바꾼다. 빼면 소스의 기본값(`blob/develop`)을 쓴다.

   `ENABLE_WEB_SEARCH` 를 `auto` 로 두면 `TAVILY_API_KEY` 가 있을 때 답변 모델이 `web_search`
   도구를 직접 부른다. 규칙집에 없는 선수·구단 정보가 이 경로로 답변된다. `off` 면 규칙집과
   KBO 데이터만 쓴다. `MAX_TOOL_ROUNDS` 는 한 질문당 검색 횟수 상한이다.

   **도구는 기본값이 전부 `off` 다.** 여기 적지 않으면 로컬은 멀쩡한데 배포본에서만
   조용히 꺼진다. 하이라이트가 켜지는 조건은 `ENABLE_HIGHLIGHTS="on"` **그리고**
   `YOUTUBE_KBO_API_KEY` 다(`config.py` 의 `highlights_enabled`). Tavily 는 폴백일 뿐이라
   없어도 하이라이트는 산다. 켠 뒤에는 앱 로그에서 한 줄로 확인한다 —
   `하이라이트 완료 stage=ok` 가 보이면 정상이고, `하이라이트 0건 stage=...` 이면
   그 단계 이름이 원인을 말한다.

   `GOOGLE_MAPS_EMBED_API_KEY` 가 없으면 지도는 조용히 생략된다(오류가 아니다).

   `APP_ACCESS_PIN` 을 넣으면 코드를 아는 사람만 질문할 수 있다. 빼면 누구나 쓸 수 있다.
   공개 주소로 배포하면서 요금을 통제하려면 반드시 넣는다.
8. Save 를 누르고 Deploy 를 누른다.

`API_BASE_URL` 을 **넣지 않는 것**이 단일 프로세스 모드의 신호다. 넣으면 존재하지 않는 백엔드를 찾는다.

### 5.3 배포 후 확인

1. 사이드바에 `● 준비됨` 과 청크 수가 보인다.
2. 예시 질문을 누르면 답변이 흐르고 근거 배지가 붙는다.
3. 야구 외 질문에는 거부 문장이 나온다.
4. 원문 PDF 열기가 저장소의 규칙집을 연다.

## 6. 알아 둘 점

- 무료 요금제는 **공개 앱만** 가능하다.
- 트래픽이 12시간 없으면 앱이 잠든다. 방문자가 눌러야 깨어난다. 시연 전에 한 번 열어 둔다.
- Neon 은 5분 유휴 후 컴퓨트를 멈춘다. 데이터는 남고 접속 시 자동으로 깨어난다.
- 데이터베이스 지역과 앱 지역이 멀면 질문마다 왕복 지연이 붙는다.
  검색 경로는 커넥션을 턴당 한 번만 열도록 되어 있다.
- 무료 요금제는 공개 앱만 가능하므로 주소를 아는 사람은 페이지를 열 수 있다.
  `APP_ACCESS_PIN` 을 넣으면 코드를 모르는 사람은 질문할 수 없다.
  다만 네 자리는 경우의 수가 1만 가지라 강한 인증이 아니다. 다섯 번 틀리면 5분 대기가 걸리지만,
  민감한 용도라면 자릿수를 늘리거나 다른 인증을 쓴다.
- 배포 전에 OpenAI 프로젝트에 지출 한도를 걸어 둔다. 질문마다 요금이 나간다.
- 원문 PDF 는 저장소 파일을 가리킨다. MinIO 는 배포본에서 쓰지 않는다.
